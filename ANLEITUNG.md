# Holo-Logbuch auf GitHub Pages veröffentlichen

1. Auf github.com kostenlos anmelden.
2. Oben rechts „+“ → „New repository“. Name z. B. `holo-logbuch`, auf **Public** stellen, „Create repository“.
3. Auf der Repository-Seite „uploading an existing file“ anklicken und **alle Dateien aus diesem Ordner** hineinziehen
   (index.html, manifest.webmanifest, sw.js, die drei icon-Dateien sowie die Ordner `lib` und `fonts`). Unten „Commit changes“.
4. „Settings“ → links „Pages“ → bei „Branch“ `main` und `/ (root)` wählen → „Save“.
5. Nach 1–2 Minuten steht oben die Adresse, z. B. `https://DEINNAME.github.io/holo-logbuch/`.

Auf dem Android-Handy die Adresse in Chrome öffnen → Menü (drei Punkte) → „App installieren“.
Die App läuft dann im Vollbild mit eigenem Symbol und funktioniert nach dem ersten Öffnen auch offline.

**Updates:** Neue `index.html` hochladen und in `sw.js` die Zahl in `holo-logbuch-privat-v1` um eins erhöhen (v2, v3 …).
Die Daten deiner Nutzer bleiben dabei erhalten.

**Hinweis:** Die Daten liegen im Browser des jeweiligen Geräts. Die Version auf GitHub und die Claude-Version
haben getrennte Daten, weil es verschiedene Adressen sind.

## Als Bildschirmschoner

In der App unter Einstellungen → „Bildschirmschoner“ eine Zeit wählen. Nach dieser Zeit ohne Berührung
schwimmt dein Tier im Vollbild mit Uhrzeit, und der Bildschirm bleibt an. Tippen beendet ihn.
Direkt im Schoner-Modus starten: an die Adresse `?schoner=1` anhängen,
z. B. `https://DEINNAME.github.io/holo-logbuch/?schoner=1`.
